# 大模型训练微调整体实现技术说明

> 本文描述当前仓库中“大模型训练/微调”能力：**Code + LoRA 主通道**（`LLMTrainer`）+ 可选 LLaMA-Factory 骨架；运维 API 与 Web 控制台。  
> 详细落地方案见 [`docs/大模型微调实现方案.md`](../docs/大模型微调实现方案.md)。

---

## 1. 使用流程

1. （可选）LabelStudio 标注：`labelstudio-deploy/` + `configs/llm_train/labelstudio/*.xml`  
2. 转换/校验：`POST /train/llm/data/convert`、`POST /train/llm/data/validate`  
3. 启动训练：`POST /train/llm/start`（`mode=code`）或 CLI：`python run_llm_training.py --config configs/llm_train/train_lora.yaml`  
4. 监视：`GET /train/llm/status`、`/train/llm/jobs/{id}/metrics|logs`  
5. 产物：`outputs/llm_train/{job_id}/adapter`，或 `GET /train/llm/artifacts`  
6. Web UI：`tests/web/train-llm-console.html`

---

## 2. 模块映射

| 模块 | 路径 |
|------|------|
| API | `app/api/train_llm_admin.py`（挂载前缀 `/train`） |
| 模型 | `app/models/train_llm.py` |
| 调度 | `app/train/llm/orchestrator.py` → `LLMTrainingOrchestrator` |
| 服务 | `app/train/llm/training_service.py` → `LLMTrainingService` |
| 训练器 | `app/train/llm/trainer.py` → `LLMTrainer` |
| 数据管道 | `app/train/llm/data_pipeline.py` |
| Factory 骨架 | `app/train/llm/factory_adapter.py` |
| CLI | `run_llm_training.py` |
| 配置 | `configs/llm_train/` |

小模型训练位于 `app/train/yolo/`，与 LLM 包隔离。

---

## 3. 双通道

- **code（推荐）**：`LLMTrainer`，支持 `modality=text|vision`，LoRA + HF Trainer。  
- **factory**：适配器占位；未接线时会明确报错，引导使用 code 通道。

---

## 4. 数据

统一 JSONL schema（`id/modality/task_profile/messages/images/meta`）。  
内置 `task_profile`：`vl_ops`、`defect_vl`、`chat_sft`。  
样例：`configs/llm_train/samples/`。

---

## 5. 依赖

见 `requirements-大模型训练.txt`（transformers / peft / datasets / accelerate / pillow 等）。  
训练依赖不强制打入在线推理镜像。
