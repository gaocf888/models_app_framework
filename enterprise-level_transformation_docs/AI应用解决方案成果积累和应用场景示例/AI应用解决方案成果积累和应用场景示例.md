## 3. 行业场景解决方案

> 从通用业务问题出发归纳方案名称，便于跨行业复用；具体落地示例见第二部分「应用场景示例」（可含当前电力项目实例）。

### 3.1 知识问答与业务数据查询一体化方案

| 维度 | 内容 |
|------|------|
| **业务问题** | 制度/规程/案例分散难查；业务台账统计要找人写查询；多轮沟通中「它/上次那个」容易答偏 |
| **方案要点** | 统一入口承接「问知识」与「查数据」；自动判断走知识库还是走业务库；支持多轮续问与推荐追问 |
| **适用对象** | 一线作业、值班、知识管理、业务支持人员 |
| **方案价值** | 7×24 自然语言入口；少翻资料、少找人；统计类问题不必手写查询 |
| **跨行业适用** | 制造、能源、交通、政务等「有规程知识 + 有业务台账」的组织均可套用 |

### 3.2 多源业务综合分析方案

| 维度 | 内容 |
|------|------|
| **业务问题** | 异常研判、策略建议、健康评估、事故溯源等依赖人工跨系统拼数、写稿，周期长、格式不统一 |
| **方案要点** | 按分析专题自动取数并生成结构化报告；数据不足时说明缺口而非硬编；支持可配置的专项分析模板（含分方向、分层次溯源类报告） |
| **适用对象** | 业务专工、管理决策、调查分析相关人员 |
| **方案价值** | 缩短初判与起稿时间；报告结构统一、便于复核与交接 |
| **跨行业适用** | 设备运维、质量分析、安环事件分析、运营复盘等「多源取数 + 结构化报告」场景 |

### 3.3 多模态现场研判方案

| 维度 | 内容 |
|------|------|
| **业务问题** | 现场拍照/取证后，仍需回办公室查历史记录与制度规范，决策链条长 |
| **方案要点** | 图像研判、历史数据查询、知识检索并行，再合成风险与处置建议；关键范围/对象不清时可人工确认 |
| **适用对象** | 巡检、现场作业、应急处置人员 |
| **方案价值** | 「拍即诊」辅助现场讨论；历史与规范联动，减少信息孤岛 |
| **跨行业适用** | 巡检运维、工程验收、安环检查、售后服务等「现场图像 + 台账 + 规范」场景 |

### 3.4 业务文档结构化整理方案

| 维度 | 内容 |
|------|------|
| **业务问题** | Word/PDF 等业务报告人工录入慢、字段不统一，难以入库与后续分析 |
| **方案要点** | 长文档自动分块处理，经多阶段抽取形成标准业务记录；支持扫描件与复杂表格类文档 |
| **适用对象** | 文档处理、台账录入、数据治理相关人员 |
| **方案价值** | 录入由「逐页抄录」转为「上传后复核」；格式统一可入库 |
| **跨行业适用** | 检测报告、巡检记录、验收单、工单附件等「非结构化文档转结构化数据」场景 |

### 3.5 作业风险行为检测与研判方案

> 对应《AI+安全生产大小模型协同创新应用方案》二级安全生产准实时风险研判能力；方案形态可复用到各类作业现场安监。

| 维度 | 内容 |
|------|------|
| **业务问题** | 作业现场复杂：仅靠专业小模型做目标检测，易误报漏报；难理解「人—设备—环境」关系与作业行为语义，风险分级仍依赖人工复核 |
| **方案要点** | 在视频分析 → 设备/人员识别 → 风险目标检测 → 分级预警链路中，对疑似风险画面引入多模态大模型：基于小模型检出目标与图像做二次风险行为检测与研判，确认是否真实风险并完成自动分级 |
| **适用对象** | 安监人员、智慧工地/现场管理、应急值守 |
| **方案价值** | 风险行为可语义理解；二次研判降低误报；按风险标准自动分级，提升复杂场景准实时研判能力 |
| **核心做法** | **专业小模型目标检测结果 & 图像 → 多模态大模型二次风险行为检测与研判**（大小模型协同） |
| **跨行业适用** | 建筑、能源、制造、仓储物流等「视频安监 + 风险行为语义研判」场景 |

## 5. 典型场景示例详述

### 示例一：AI 问答

- **做什么**：统一承接规程/案例问答与台账类查数；支持多轮续问（「它」「第几点」）与推荐追问。  
- **效果**：7×24 自然语言入口；少翻册、少找人；统计类问题不必手写查询。  
- **应用场景**：① 值班/一线查规程、案例，少翻册、少找人；② 运行台账统计用自然语言提问，不必找人写查询。

### 示例二：超温分析

- **做什么**：按机组/受热面/时间等需求自动取多维数据，生成结构化超温分析报告。  
- **效果**：缩短信息收集与初判时间；报告结构统一；数据不足可说明缺口。  
- **应用场景**：① 超温异常后专工快速拿到结构化初判报告；② 报告口径统一，便于交接复核与管理决策。

### 示例三：检修策略 / 四管健康解读

- **做什么**：基于设备状态、缺陷与规程知识输出策略建议；或对四管健康检测数据做解读与趋势提炼。  
- **效果**：减轻专工拼信息与通读报告负担，提升讨论起点质量。

### 示例四：泄爆溯源分析

- **做什么**：面向泄漏/爆管，按多个排查方向与「直接原因 → 中期因素 → 根因」层次输出溯源与防控建议。  
- **效果**：事故调查有规范草稿起步；案例与规程可引用、可复查。  
- **应用场景**：① 调查有规范溯源草稿，减少遗漏排查方向；② 防控建议可讨论复核，缩短起稿与汇报准备。

### 示例五：看图诊断（缺陷识别 / 泄爆）

- **做什么**：上传现场照片（泄爆场景可无图）+ 自然语言描述，联动历史数据与规程知识，输出研判与处置建议；范围不清可人工确认。  
- **效果**：现场「拍即诊」辅助决策；历史与规程不再割裂。  
- **应用场景**：① 巡检/停机现场拍照即可辅助研判；② 历史缺陷与规程建议一并给出，支撑现场处置。

### 示例六：检修报告结构化提取

- **做什么**：Word/PDF 检修报告自动抽取为标准缺陷 JSON（位置、类型、壁厚等），长文档分块并行处理。  
- **效果**：录入效率与格式一致性显著提升，便于入库与后续分析。  
- **应用场景**：① 文档岗从抄录改为复核，缩短入库周期；② 字段口径统一，便于后续统计与专项分析。

### 示例七：自然语言查数与知识库运维

- **做什么**：独立问数接口供其他系统复用；知识库支持资料入库、域隔离与检索调优。  
- **效果**：查数能力统一、安全边界一致；知识资产可运营，支撑「答得准、不串域」。

### 示例八：风险行为检测与研判（大小模型协同）

- **做什么**：专业小模型先识别作业现场目标（人/设备等）并给出检测框与图像；多模态大模型基于检测结果与画面做二次风险行为检测与研判（如是否吊车下站人），确认风险并自动分级。  
- **效果**：降低小模型误报；理解复杂作业语义；支持准实时风险分级预警。  
- **应用场景**：① 安监值守降低误报干扰，聚焦真实高风险行为；② 作业语义可理解并自动分级，支撑准实时预警处置。

## 6. 场景效果共性（收束）

1. **提效**：问规程、查台账、写分析初稿、录缺陷——从「人找系统」变为「自然语言驱动系统」。  
2. **提质**：回答尽量有资料/数据依据；报告结构统一，减少随意表述。  
3. **可控**：资料不足会说明；关键环节可确认；查数只读不改库。  
4. **可复制**：同一套行业方案，换知识域、接业务库即可推广到同类场景。
