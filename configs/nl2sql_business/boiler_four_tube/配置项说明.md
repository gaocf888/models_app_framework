# 锅炉四管 NL2SQL 业务配置包说明（boiler_four_tube）

> 路径：`configs/nl2sql_business/boiler_four_tube/`  
> 启用：`NL2SQL_BUSINESS_DOMAIN=boiler_four_tube`  
> 加载入口：`app/nl2sql/nl2sql_business_profile.py`

## 目录一览

| 文件/目录 | 用途 | 运行时 |
|-----------|------|--------|
| `profile.yaml` | 域入口：DB 默认、NL2SQL 开关、表白名单路径、RAG 命名空间 | **必读** |
| `table_scope.txt` | 允许查询的表白名单（与部署 ANALYSIS 表白名单对齐） | **必读** |
| `join_whitelist.txt` | 人工 JOIN 补充；库 FK 反射仍自动纳入 | **必读** |
| `semantic/` | 语义资产占位（当前默认不启用语义链接） | 可选 |

本包**无**独立 `scope_lexicon.json` / `entity_rules.json`：范围词表默认指向仓库根下通用锅炉别名文件；实体规则默认关闭（`entity_rules_file: ""`）。

## profile.yaml 关键字段（摘要）

- **db.\***：TiDB/MySQL 业务库默认；密码禁止写入；显式 `DB_*` / `DB_URL` 优先。
- **nl2sql.semantic_link_enabled**：默认 `false`（与地降相反）；启用前须补齐 `semantic/` 资产。
- **nl2sql.semantic_dict_path**：语义目录占位路径。
- **nl2sql.scope_lexicon_file**：默认 `configs/nl2sql_scope_device_aliases.json`（锅炉设备别名，不在本目录）。
- **nl2sql.entity_rules_file**：空字符串表示不加载实体规则文件。
- **nl2sql.prompt_default_version**：默认 `v2`。
- **nl2sql.schema_link_catalog_mode**：默认 `legacy_wide`（宽 catalog；地降为 `linked_only`）。
- **nl2sql.anchor_fallback_\***：图像诊断类分析类型的锚点时间回退。
- **tables.\***：白名单与 JOIN 白名单路径。
- **rag.namespaces**：RAG 命名空间约定（与地降同名空间模式，内容按部署摄入）。

## semantic/ 子项

| 文件 | 说明 |
|------|------|
| `manifest.yaml` | 语义资产占位说明；`semantic_link_enabled=false` 时不加载 |

启用语义链接前，需按地降包结构补齐 `metrics.yaml` / `synonyms.yaml` / `dimensions/*` 等。

## 与地降包差异（速查）

| 项 | boiler_four_tube | subsidence |
|----|------------------|------------|
| 方言 | tidb / mysql | postgres |
| 语义链接 | 默认关 | 默认开 |
| catalog 模式 | legacy_wide | linked_only |
| 范围词表 | 仓库级设备别名 JSON | 包内 `scope_lexicon.json` |
| 实体规则 | 默认无 | 包内 `entity_rules.json` |

## 维护提示

1. 表白名单变更须与生产允许表、分析智能体表范围对齐。  
2. 切域时只改 `NL2SQL_BUSINESS_DOMAIN`，勿把地降 PG 连接写进本包。  
3. 详细说明见企业级 NL2SQL / 锅炉相关改造文档。
