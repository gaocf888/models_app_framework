# 综合分析报告规格说明（analysis_agent_reports）

> 路径：`configs/analysis_agent_reports/`  
> 加载：`app/analysis_agent/report_spec.py` → `load_report_spec()`  
> 详细命名约定亦见同目录 `README.md`

## 目录一览

| 文件 | 用途 | 运行时 |
|------|------|--------|
| `*.analysis_agent.json` | 报告规格兜底：章节 + 可选内嵌 `plan` | **必读**（按 analysis_type） |
| `{type}.{plan_template_version}.json` | 带逻辑版本号的优先规格（可选） | 有则优先于兜底 |
| `README.md` | 命名与结构说明 | 文档 |

## 当前报告类型（文件名 → analysis_type）

| 文件 | 业务 |
|------|------|
| `overheat_guidance.analysis_agent.json` | 锅炉超温指导 |
| `leakage_burst_analysis.analysis_agent.json` | 泄漏爆管分析 |
| `maintenance_strategy.analysis_agent.json` | 检修策略 |
| `four_tube_health_interpretation.analysis_agent.json` | 四管健康解读 |
| `subsidence_daily/weekly/monthly/quarterly/yearly.analysis_agent.json` | 地降日/周/月/季/年报 |

## 加载顺序

```text
{analysis_type}.{ANALYSIS_AGENT_PLAN_TEMPLATE_VERSION}.json
→ {analysis_type}.analysis_agent.json
```

默认版本 env：`ANALYSIS_AGENT_PLAN_TEMPLATE_VERSION`（如 `analysis_agent_v1`）。

## JSON 结构（摘要）

- **chapters[]**：`static_markdown` / `llm_section` 等章节定义。  
- **plan.items[]**（可选）：内嵌 NL2SQL 取数计划；未内嵌时回退 `prompts.yaml` 的 `analysis_agent_plan_{type}`。

## 相关配置（不在本目录）

| 用途 | 位置 |
|------|------|
| 章节合成 system / 数据计划 Prompt | `configs/prompts.yaml` |
| NL2SQL 业务域 | `configs/nl2sql_business/<domain>/` |
| 地降重点监测区 | `configs/nl2sql_business/subsidence/semantic/dimensions/key_monitoring_areas.yaml` |
| 自动报告粗略方案 | `docs/基于地降所项目改造/自动报告生成实现方案(粗略版).md` |
| 逻辑 plan 版本 | env `ANALYSIS_AGENT_PLAN_TEMPLATE_VERSION` |

## 维护提示

1. 改章节结构、outline、constraints：**只改本目录 JSON**，勿再写回 `prompts.yaml` 的 report 块。  
2. 地降/锅炉报告与当前 `NL2SQL_BUSINESS_DOMAIN` 对齐，避免跨域表白名单。
