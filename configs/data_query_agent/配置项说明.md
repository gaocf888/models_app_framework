# 数据查询智能体配置说明（data_query_agent）

> 路径：`configs/data_query_agent/`  
> 启用：`DATA_QUERY_AGENT_ENABLED=true`（接口 `/data-query-agent/*`）  
> 加载：`app/data_query_agent/catalog.py` 等；路径可由 `DATA_QUERY_AGENT_*` / `DataQueryAgentConfig.libraries_file` 覆盖

## 目录一览

| 文件 | 用途 | 运行时 |
|------|------|--------|
| `libraries.yaml` | 监测库注册表（library_id → 表 / 指标 / 列 / 同义词 / HUD） | **必读** |
| `plan.yaml` | 程序问句模板（列表 / HUD 时序，按 grain 分叉） | **必读** |
| `golden.json` | 联调/回归黄金样例 | 测试/评测 |

## libraries.yaml（摘要）

- **default_library_id**：未指定监测类型时的默认库（地降多为 `fcb`）。  
- **groups[]**：前端树分组（岩土 / 流体 / 星地等）。  
- **libraries[]**：一库一表；关键字段 `id`、`table`、`core_metric`、`columns`、`synonyms`、`hud_supported`。  
- **hitl_prompt**：库意图不清时的选库话术。

须与 NL2SQL `device_type.yaml` / 表白名单同源，禁止跨其它 `t_data_wash_*`。

## plan.yaml（摘要）

- **q_list**：站点 / 行政区 / 全市 列表问句模板。  
- **q_hud_series**：HUD 时序问句模板（同 grain 分叉）。  
- **hint_template**：注入 NL2SQL 的范围提示。  
- 占位符由 `acquire._render_question` 填充（`{table}`、`{scope_block}` 等）。

## 相关配置（不在本目录）

| 用途 | 位置 |
|------|------|
| 业务库 / 方言 | `NL2SQL_BUSINESS_DOMAIN` + `nl2sql_business/<domain>/` |
| Checkpoint / Redis | env `DATA_QUERY_AGENT_CHECKPOINT_*`、`DATA_QUERY_AGENT_SESSION_*` |

## 维护提示

1. 增删监测库：同步改 `libraries.yaml` 与 NL2SQL 白名单/语义。  
2. 改列表或 HUD 口径：优先改 `plan.yaml` 模板，保持「单库单表」约束。  
3. 本模块是**查询台**，与智能客服 `/chatbot` 对话查数分工，勿混用 HITL 选库到客服。
