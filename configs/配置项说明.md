# configs 配置总览

> 路径：`configs/`  
> 作用：应用运行时业务/Prompt/图谱/小模型等**非密钥**配置（密码与连接串走 `.env`）  
> 容器内通常挂载为 `/workspace/configs`

## 一级目录

| 目录 | 用途 | 启用 / 入口 |
|------|------|-------------|
| `nl2sql_business/` | NL2SQL 业务域包（表白名单、语义、RAG 源） | `NL2SQL_BUSINESS_DOMAIN`；见各子域 `配置项说明.md` |
| `chatbot_business/` | 智能客服域包（意图词表、话术、锁库；`funnel` 模式下的意图示例问句） | `CHATBOT_DOMAIN`；见 `boiler/`、`subsidence/` 说明（含意图 rules/funnel 释义） |
| `data_query_agent/` | 「数据查询」台：库注册表、程序问句模板、黄金样例 | `DATA_QUERY_AGENT_*`；见本目录说明 |
| `analysis_agent_reports/` | 综合分析报告规格 JSON（章节 / 内嵌 plan） | `report_spec.load_report_spec`；见本目录说明 |
| `analysis_agent_slots/` | 槽位相关占位（当前为空，预留） | — |
| `llm_train/` | LLM 微调任务 / Label Studio / LoRA 训练 YAML | 训练管理 API；见本目录说明 |
| `monitoring/` | Analysis Trace 告警规则**权威副本**（需同步到 monitoring-deploy） | 见 `monitoring/README.md` |

## 一级文件（常用）

| 文件 | 用途 |
|------|------|
| `prompts.yaml` | **主 Prompt 库**（chatbot / nl2sql / analysis_agent 等 scene+version） |
| `prompts_bak_*.yaml` / `prompts_bak_new.yaml` | Prompt 历史备份，**勿作运行时主配置** |
| `chatbot_anaphora.yaml` | 客服指代消解运行时参数（规则阈值、Coref 窄触发等） |
| `graph_schema.yaml` | GraphRAG 图谱 schema（实体/关系） |
| `graph_schema.yaml.example` | schema 示例模板 |
| `graph_extraction.yaml` | 图谱抽取流水线参数 |
| `nl2sql_scope_device_aliases.json` | 锅炉等通用设备/范围别名（锅炉 NL2SQL 包默认引用） |
| `small_models.yaml` | 小模型通道 / 推理运行配置 |
| `small_model_algorithms.yaml` | `algor_type` → 算法条目注册表 |

## 域切换约定（地降 / 锅炉）

```text
地降：CHATBOT_DOMAIN=subsidence + NL2SQL_BUSINESS_DOMAIN=subsidence
锅炉：CHATBOT_DOMAIN=boiler     + NL2SQL_BUSINESS_DOMAIN=boiler_four_tube
```

二者**同名约定、独立 env**，加载器不合并。

## 维护提示

1. 改 `prompts.yaml` / 业务包 / 报告 JSON 后按需重启应用；NL2SQL RAG 源变更须 **re-ingest**。  
2. 密钥、DB 密码、API Key **不进**本目录。  
3. 子目录详细字段见各自 `配置项说明.md`（`nl2sql_business/*` 已有）。
