# 数据库说明

## 当前北京市地面沉降检测技术主要包括如下几种：
1. 基岩标-分层标  -- 对应数据库 t_data_wash_jyb、t_data_wash_fcb 表
2. 地下水位井  -- 对应数据库 t_data_wash_dxswj 表
3. 孔隙水压力  -- 对应数据库 t_data_wash_kxsylj 表
4. 光纤  -- 对应数据库 t_data_wash_gq 表
5. GNSS  -- 对应数据库 t_data_wash_gnss 表
6. 气象站  -- 对应数据库 t_data_wash_qxz 表

目前主要以 基岩标-分层标 的检测数据为主要地面沉降衡量、评估和分析的数据，其他检测技术的检测数据作为辅助数据；
数据过滤条件主要包括：行政区划-监测站点、日期时间。我理解当前地降所针对NL2SQL相关，范围主要对应 行政区划-监测站点（之前锅炉的为锅炉、受热面、检测位置等），日期时间与之前锅炉实现一致;
