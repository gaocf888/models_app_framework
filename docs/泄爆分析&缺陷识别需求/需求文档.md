1.泄爆分析
	a.需求
		i.AI问答界面选择“泄爆分析”，然后选择选定管段位置，选择事故发生时间
		ii.数据计划 拉取 最近三天的以下数据：
			1.管段基础参数：规格材质、壁厚限值、胀粗率限值、壁温限值、累计运行时长。
			2.检修处置历史：近 3 次壁厚记录、遗留问题处置结果、年平均减薄速率、泄爆记录、补焊记录、同区域过往换管。
			3.壁温超温数据：对应管段累计超温时长、超温峰值、壁温偏差。
			4.吹灰运行数据：对应区域吹灰器吹灰频次、吹扫压力、累计吹扫时长。
			5.烟气煤质数据：对应区域烟温 / 烟速 / 飞灰浓度。
		iii.分析结果：
			1.按照 “直接爆口原因 - 中期劣化因素 - 底层根因” 三层逻辑开展溯源，从超温热应力损伤、飞灰冲刷磨损、烟气 / 水汽侧腐蚀、焊接与材质原始缺陷、运行操作偏差五大类方向逐项验证
			2.分析结果同位置、同类型的历史事故案例、同类型机组典型故障处理经验、对应标准规程条文、防控技术资料，自动推送“同类爆管预防措施”“同区域改造案例” 等延伸问题
	b.需求澄清明确：
		1.入参包括用户自然语言问题(管段位置、事故发生时间)、缺陷图片(可选)【用户问题 用于NL2SQL中 时间/范围 解析，并动态改写sql中时间和相关范围条件】
		2.相关的数据查询要依据 事故发生时间的近3天数据
		3.分析结果依据 超温热应力损伤、飞灰冲刷磨损、烟气 / 水汽侧腐蚀、焊接与材质原始缺陷、运行操作偏差五大类方向，然后按照 直接爆口原因 - 中期劣化因素 - 底层根因 三个层面输出；
		4.依据 用户问题+缺陷图片分析结果，然后进行RAG知识库召回 同位置/同类型的历史事故案例、同类型机组典型故障处理经验，对应标准规程条文、防控技术资料
		5.上述最终LLM分析，要依据缺陷图片分析结果、 查询数据(NL2SQL)、RAG召回知识，从直接原因、劣化原因、根本机理原因三个方面进行泄爆原因分析输出
2.缺陷识别
	a.需求
		i.根据缺陷图片，自动识别  缺陷类型判定（水冷壁、过热器、再热器、省煤器全受热面典型缺陷，包括飞灰冲刷磨损沟槽、点蚀 / 均匀腐蚀坑、管壁胀粗、轴向 / 周向表面裂纹、焊口夹渣 / 未熔合成型缺陷、防磨瓦脱落 / 歪斜、管间氧化皮堆积等类型）
		ii.知识库中 匹配同类型缺陷的历史处置案例
		iii.数据计划：查询用户指定(用户问题)的区域位置的相关数据(同上方 泄爆分析数据)：
			1.管段基础参数：规格材质、壁厚限值、胀粗率限值、壁温限值、累计运行时长。
			2.检修处置历史：近 3 次壁厚记录、遗留问题处置结果、年平均减薄速率、泄爆记录、补焊记录、同区域过往换管。
			3.壁温超温数据：对应管段累计超温时长、超温峰值、壁温偏差。
			4.吹灰运行数据：对应区域吹灰器吹灰频次、吹扫压力、累计吹扫时长。
			5.烟气煤质数据：对应区域烟温 / 烟速 / 飞灰浓度。
		iv.针对不同风险等级缺陷，结合上述图片解析、知识库召回的历史案例、查询的相关数据，输出可直接落地的现场处置方案：一般缺陷明确运行监护要求与下次检修的复测周期、检测方式；以及打磨补焊、换管、加装防磨护瓦等标准检修工序的工艺要求；
	b.需求澄清明确：
		i.区域位置 需要从用户问题中解析 【同 泄爆分析，用于NL2SQL中 时间/范围 解析，并动态改写sql中时间和相关范围条件】
		ii.需要基于哪些维度数据进行 处置方案 的分析（需要提供数据查询逻辑--后续客户提供，暂时没有）
		iii.同类型缺陷的历史处置案例（用户问题+缺陷图片分析结果，然后进行RAG知识库召回 同类型缺陷的历史处置案例）
		iv.该基于图片的缺陷分析，目前是基于大模型通用能力进行分析，效果可能不会太好（需要后期基于缺陷图片数据集进行微调）
