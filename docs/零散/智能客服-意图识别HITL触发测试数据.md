意图 HITL 不认业务主题，只认「查数说法 + 知识说法」是否混在一句里。超温以外，缺陷/检修/壁厚/泄爆/工况等都能触发。

其它领域可演示问法（实测会 YES）
缺陷 / 台账 / 工单

「1号炉当前负荷是多少，为什么负荷波动影响燃烧？」
「查询主汽温度记录，超标标准是什么？」
设备清单

「查询最近缺陷记录，为什么会频繁出现裂纹？」
「列出本月缺陷单有多少条，常见原因是什么？」
「台账里工单有多少，处理依据是什么？」
检修

「查询上次检修记录，检修周期标准是什么？」
「列出#3炉检修记录，如何预防同类缺陷？」
「统计本季度检修工单数量并说明为什么延期」
壁厚 / 四管健康

「统计水冷壁壁厚测点有多少，减薄机理是什么？」
「列出壁厚不合格测点，危害和风险有哪些？」
泄漏 / 泄爆

「今天有多少泄漏报警，什么原因？」
「查询最近泄漏记录有多少，爆管原理是什么？」
「列出泄爆相关台账，如何预防？」
运行参数

「列出受热面设备清单，材质定义是什么？」
这些与产品里的缺陷台账、检修策略、四管健康、泄爆等场景同构，只是客服单轮把「查数」和「问为什么/标准/预防」揉在一起。

对照：同样主题但不 HITL
「查询最近缺陷记录」→ 纯查库
「过热器爆管常见原因是什么？」→ 纯知识
「锅炉四管泄漏的应急处置流程是什么？」→ 纯知识
「上次检修是什么时候？」→ 纯查库（「上次」）
记一句就够
任意主题，只要一句里同时出现大致两类词就会弹：

查数侧：有多少 / 统计 / 查询 / 列出 / 台账 / 记录 / 工单 / 清单…
知识侧：什么原因 / 为什么 / 机理 / 原理 / 如何预防 / 标准是什么 / 依据 / 危害 / 风险…
超温只是最常见的演示题材，不是唯一可触发的。
