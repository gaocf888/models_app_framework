# 17 · 模型生态与选型（不绑定单一项目）

> 面试定位：证明你能按 **任务、成本、合规、延迟、上下文、工具能力** 选模型，而不是只会报一个自家部署的名字。  
> 预计：40 分钟。  
> 行业面：闭源 API、开源权重、中文/英文/代码/推理/多模态分工。

---

## 0. 30 秒能讲清楚

没有「最强模型」，只有「约束下的最优」。闭源 API 适合通用能力、工具和快速验证；开源/私有化适合数据不出域、可微调、可控成本。选型先列 **任务类型（闲聊 / RAG / SQL / 推理 / 代码 / 视觉）**，再比价格、上下文、结构化输出、函数调用、中文与领域评测。

---

## 1. 生态地图（2025–2026 面试够用）

| 阵营 | 代表 | 面试怎么定位 |
|------|------|----------------|
| 闭源通用 | GPT 系列、Claude、Gemini | 通用最强档、工具/长上下文/安全策略成熟，数据出境与单价是代价 |
| 开源稠密 | Llama、Qwen、Gemma、GLM、Yi | 可私有化、可微调；中文常看 Qwen/GLM |
| 开源 MoE | Mixtral、DeepSeek-V3、Qwen-MoE | 同激活量更强或更便宜，服务化更复杂 |
| 推理模型 | o 系列、DeepSeek-R1、Qwen thinking | 测时算力换正确率，延迟和 token 费高 |
| 代码 | Codex 类、DeepSeek-Coder、Qwen-Coder、Codestral | 补全 vs 仓库级 Agent 不是同一档 |
| 嵌入/重排 | bge、GTE、E5、GTE-Qwen、Cohere Rerank、BGE-reranker | **不要用聊天模型当向量** |
| 端侧 | Phi、Qwen-tiny、Llama 小尺寸、GGUF | 隐私、离线、弱网 |

金句：

> 我选模型先分「生成 / 嵌入 / 重排 / 分类路由 / 检测」五类，而不是一个 LLM 包打天下。

## 2. 开源 vs 闭源 vs 混合

| 维度 | 闭源 API | 开源自托管 | 混合 |
|------|----------|------------|------|
| 效果上限 | 通常更高、迭代快 | 受卡和工程限制 | 简单走 API，敏感走本地 |
| 数据 | 要审协议与区域 | 可完全内网 | 按字段分流 |
| 成本 | 按 token，低 QPS 便宜 | 固定资本 + 电，高水位更划算 | 最常见企业形态 |
| 定制 | 有限（微调接口/偏好） | 全权 SFT/LoRA | 本地 LoRA + 云通用 |
| 运维 | 几乎为零 | 推理、扩缩、补丁全自己来 | 两套 SLA |
| 锁定 | 供应商 | 权重+引擎 | 用兼容 API 降绑定 |

面试官问「为什么不直接上 GPT-4」时：答合规、延迟内网、成本曲线、可复现版本，而不是「开源更强」。

## 3. 选型检查表（白板可用）

1. **任务**：抽取/分类 → 小模型或低温结构化；开放写作 → 强生成；数学代码 → 推理模型或专用代码模。  
2. **语言与领域**：中文制度、电力术语要看中文基准和领域抽样，不看英文 Arena 第一。  
3. **上下文**：合同/代码库要 100K+；客服 8K~32K 够用。  
4. **工具**：是否稳 Function Calling / JSON Schema / 并行工具。  
5. **多模态**：是否真要像素级理解，还是 OCR + 文本模型更稳。  
6. **SLO**：TTFT、P95、是否必须流式。  
7. **合规**：等保、数据分类、是否可出境、日志留存。  
8. **成本模型**：输入输出单价不对称；推理模型「思维 token」也计费。  
9. **版本冻结**：生产钉死模型版本，升级走评测回归。  
10. **降级链**：主模型 → 同系列小模型 → 规则/缓存。

---

## 4. 能力不等于参数量

- 同系列 **14B 精心对齐** 可能在格式服从上打过乱 SFT 的 70B。  
- MoE「总参 671B / 激活 37B」这类数字要会读：比的是激活量与路由质量。  
- **蒸馏小模型** 在窄任务上可接近老师，泛化弱。  
- 榜单污染：训练数据可能含测试题，业务集比公开榜更可信。

---

## 5. 路由与多模型架构（行业常见）

```text
请求 → 分类/复杂度估计
     ├─ 闲聊 / 简单抽取 → 小模型
     ├─ 知识问答 → 中模型 + RAG
     ├─ 数学/代码/规划 → 推理模型（可异步）
     └─ 敏感/监管 → 本地模型 + 审计
```

相关名词：Model Router、Cascade、FrugalGPT、Speculative 也可以看成「小草稿+大验证」的路由。

## 6. 高频问答

**Q：Qwen、Llama、DeepSeek 怎么一句区分？**  
A：Llama 是英文开源生态锚点；Qwen 中文与全尺寸/端侧/嵌入配套完整；DeepSeek 以 MoE 成本与推理（R1）叙事突出。实际以你的任务评测为准。

**Q：推理模型和普通 Chat 怎么选？**  
A：要逐步证明、竞赛数学、复杂代码用推理模型；客服话术、摘要、已检索证据的阅读理解用普通 Chat，否则又慢又贵。

**Q：嵌入模型和生成模型能共用吗？**  
A：只有提供独立 embedding 接口或专门 embedding 权重时才行。用 Chat 最后一层当向量，各向异性严重，检索会差。

**Q：如何避免供应商锁定？**  
A：业务层走 OpenAI 兼容协议；Prompt 少绑专有角色标记；评测集自建；关键路径准备第二模型。
