# 大模型面试知识库

> 目标：用一套**可快速过一遍、能对着项目讲、也能答行业通用题**的文档，覆盖大模型应用开发 + 推理/训练/微调/量化等完整知识面。  
> 写法约定：每篇都按「30 秒能讲清楚 → 原理深度 → 对比选型 → 高频问答」组织；**13 才是本仓库话术**，01–12 / 17–24 以行业考点为主，不绑死单一项目。

本仓库可作为「我做过的系统」举例（FastAPI + LangGraph + vLLM + RAG/NL2SQL/Agent + LoRA）。面试仍要能离开本栈讲清 **选型权衡与行业方案**。

## 2. 本项目 ↔ 行业考点速对照

| 行业考点 | 本仓库落点 |
|----------|------------|
| 推理服务化 | `vllm-deploy/` + `VLLMHttpClient` + `POST /llm/infer` |
| RAG | `app/rag/*`：8 步摄入、语义+关键词+metadata、RRF、CrossEncoder、namespace |
| Agentic RAG / 编排 | `AgenticRAGService`、LangGraph 客服/综合分析 |
| Agent | 客服图、综合分析 V2、分析智能体、看图诊断并行图 |
| NL2SQL | `app/nl2sql/*`：Schema RAG + 校验 + 自检修正 |
| 微调 | `app/train/llm/`：Code + LoRA（PEFT + HF Trainer），可选 LLaMA-Factory |
| 嵌入/重排 | 默认 MIS-TEI HTTP；可回退 sentence-transformers |
| 会话 | Redis 热层 + 历史预算裁剪，与 vLLM `max-model-len` 对齐 |
| 小模型 | 通道 + 解码队列 + 推理线程（YOLO 等） |
| 可观测 | Prometheus / Grafana / Loki / LangSmith / 执行轨迹 |
| 国产化部署 | 昇腾 Atlas、寒武纪镜像、离线 vLLM |

细节话术见 [13](./13-本项目技术栈对照面试话术.md)。工程实现原文在 `framework-guide/`。  
**离开本仓库仍要会的行业面**在 17–24：选型、长上下文与测时算力、数据与合成、安全红队、公开榜、向量库/ANN、MCP 与约束解码、成本网关。

## 3. 口述原则（所有岗位通用）

1. **先结论，后展开**：先说「我用的是 X，因为 Y」，再补原理。  
2. **用自己的系统举例**：每答完概念，跟一句「我们项目里是……」。  
3. **主动讲权衡**：吞吐 vs 时延、召回 vs 精度、成本 vs 效果。  
4. **承认边界**：没做过的说「原理清楚、没在生产落地」，比编经历安全。  
5. **数字要有量级**：chunk 500/overlap 80、top_k、并发、上下文长度，比空概念加分。
