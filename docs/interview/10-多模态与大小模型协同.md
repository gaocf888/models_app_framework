# 10 · 多模态与大小模型协同

> 面试定位：VLM 怎么接、和 YOLO 等小模型怎么分工、看图链路怎么控风险。  
> 预计：40 分钟。  
> 本项目锚点：VLM LoRA；看图诊断（视觉 ‖ NL2SQL ‖ RAG 再合成）；客服图片预处理；小模型通道（解码队列+推理线程）；人脸等 embedding。

---

## 0. 30 秒能讲清楚

多模态大模型（VLM）把 **图像 token 和文本 token 放进同一 Decoder**（或 cross-attn 看视觉编码器）。它擅长描述、对照规范、开放问答；不擅长稳定框出缺陷坐标、每秒几十路视频。所以企业里是 **小模型做感知，大模型做理解与报告**。

---

## 1. VLM 基本结构（够面试）

常见两段：

1. **Vision Encoder**（ViT 等）→ 视觉特征  
2. **Projector / Adapter** 对齐到 LLM 隐空间  
3. **LLM Decoder** 自回归出文本  

训练常分：冻 LLM 训 projector → 图文 SFT → 可选对齐。分辨率/切 tile 越多，图像 token 越多，**上下文和 TTFT 暴涨**。

本项目训练：`modality=vision`，Processor + 图文 collator + LoRA。

---

## 2. 和大语言模型的差异（应用侧）

| 点 | 影响 |
|----|------|
| 图像 token 多 | 必须压缩、缩放、少图 |
| URL vs base64 | 集群内要让推理机能拉到（MinIO 公网或内网 URL） |
| 幻觉更隐蔽 | 「看起来像裂纹」未必是；要和检测框/点检数据交叉 |
| 位置不精确 | 要框用检测模型 |

本项目：图片先下载缩放压缩落盘，再进图；存储默认 MinIO，方便多实例和 vLLM 读同一 URL。

---

## 3. 看图诊断怎么讲（项目故事）

并行三条：

- **视觉**：VLM/规则解析用户问题与现场图  
- **NL2SQL**：工况、历史缺陷  
- **业务 RAG**：规程、案例  

汇合再合成。缺关键槽位 **HITL 澄清或换图**，不一次生成「看起来很专业的错报告」。

这是多模态面试的满分结构：**感知、数据、知识三源交叉验证。**

---

## 4. 小模型通道（CV 侧）

典型：视频流 → 解码线程 → 有界队列 → 推理线程 → 证据与回调。

要点（高并发面试）：

- 通道级锁 + 短全局锁  
- 队列不用 `empty()/qsize()` 做逻辑  
- `stop_event` + timeout 消费，防死等  
- 算法注册表（YOLO 等）与 LLM 包隔离  

和 LLM 对比：小模型是 **稳态低延迟、可批帧**；大模型是 **变长自回归**。所以架构分开，接入层统一。

---

## 5. 协同模式（答题模板）

| 模式 | 例子 |
|------|------|
| 小模型触发大模型 | 检测到超温/缺陷 → 大模型写分析 |
| 大模型调度小模型 | Agent 调检测 API 拿框 |
| 级联 | 检测框裁图 → VLM 描述 → RAG 对规范 |
| 路由 | 意图 BERT 小模型，问答大模型 |

金句：

> 能用判别式模型稳定解决的，不要用生成式模型赌。

---

## 5.1 行业补充：训练与其它模态

VLM 常见三阶段：大规模图文对训 projector（或对齐器）→ 指令图文 SFT → 可选偏好对齐。分辨率策略：固定低分、动态高分、切 tile（AnyRes）。OCR/文档模型（版面+识别）在合同/报表上往往比通用 VLM 稳。

| 模态 | 常见做法 |
|------|----------|
| 语音 | ASR → 文本 LLM；或 Speech-LLM 端到端；TTS 独立 |
| 视频 | 抽帧 + 时序采样；长视频必须检索关键帧 |
| 图文检索 | CLIP / SigLIP 双塔，不是生成模型 |
| 统一多模态 | 一个 Decoder 吃图文音，产品上仍常拆成专家模型 |

评测：MMBench、MMMU、DocVQA、OCRBench，见 [21](./21-评测基准与行业榜单.md)。

## 6. 高频问答

**Q：为什么不全部用 GPT-4o / Qwen-VL？**  
A：成本、时延、视频路数、框精度、可解释性、内网部署。VLM 做开放理解，检测做闭环指标。

**Q：多图长视频怎么处理？**  
A：抽帧、检测过滤关键帧、只把少量 tile 给 VLM；长视频理解仍是研究+工程折中。

**Q：CLIP 和 VLM？**  
A：CLIP 是图文双塔检索/分类；VLM 是生成。RAG 以图搜图可用 CLIP 类；写诊断用 VLM。

**Q：多模态幻觉？**  
A：强制引用检测结果和测点数据；VLM 只描述可见内容；分数低则人工。
