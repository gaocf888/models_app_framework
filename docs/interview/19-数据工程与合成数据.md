# 19 · 数据工程、合成数据与模型合并

> 面试定位：算法岗「数据 > 模型」；应用岗也要会讲标注、质检、防泄漏。  
> 预计：40 分钟。  
> 行业面：预训练配比、指令数据、合成数据、飞轮、合并权重。

---

## 0. 30 秒能讲清楚

大模型效果上限由数据决定：预训练看 **配比与去污**，SFT 看 **指令多样与 loss mask**，对齐看 **偏好是否真实**。合成数据能放大规模，但会 **模式坍缩、回音室、评测泄漏**。训练后还可以 **合并多个 LoRA/模型** 做能力拼接，不能替代干净数据。

---

## 1. 预训练数据工程

流水线（行业通用）：

```text
采集 → 语言/格式识别 → 去重(精确/MinHash/语义)
     → 质量打分 → 安全与 PII 过滤 → 配比混合 → 打包 token
```

| 议题 | 面试要点 |
|------|----------|
| 去重 | 网页镜像极多；近重复会浪费算力并让模型背模板 |
| 质量分类器 | 用小模型或规则分档，高质量上采样 |
| 领域配比 | 代码、数学、多语言、书籍 vs 网页，决定能力形状 |
| 毒性 / PII | 法律与品牌风险；去不干净会对齐补不完 |
| Token 预算 | 现代故事是「看过多少 token」，不是 epoch |
| 退火 / 末期数据 | 训练后期提高高质量与长上下文比例 |

**数据污染（Contamination）**：测试集进了训练集，公开榜虚高。对策：n-gram 检测、后发集、业务自建集。

---

## 2. 指令 / 偏好数据

| 类型 | 字段 | 质量陷阱 |
|------|------|----------|
| SFT | messages、可选 tools | 用户侧算了 loss；全是「好的，当然」 |
| 偏好对 | prompt, chosen, rejected | rejected 太弱等于没训；标注员标准漂 |
| 工具调用 | 真实 tool schema + 结果 | 编造的 API 会让模型乱调 |
| 多轮 | 指代、拒绝、澄清 | 只有单轮会「不会对话」 |
| 多语言 | 平行或母语母写 | 翻译腔 |

原则：**多样性 + 正确性 + 覆盖失败态（拒答、不会、要澄清）**。

标注流程：指南 → 试标对齐 Kappa → 抽检 → 对抗题（越权、注入）。

---

## 3. 合成数据（必考）

做法：强模型生成指令/回答/思维链/硬负例；Self-Instruct、Evol-Instruct、反向翻译、从种子演化难度。

| 好处 | 风险 |
|------|------|
| 便宜、可扩规模 | 风格单一，多样性假象 |
| 可定向补短板 | 老师的幻觉被放大 |
| 可生成思维链 | 泄漏评测题面 |
| 可造难负例 | 与人类真实分布偏移 |

面试稳妥句：

> 合成数据做 **扩写与难例**，人类做 **验收与边界**；每批都用规则+小模型+抽检过滤，并和真实日志混洗。

**飞轮**：线上日志 → 难例挖掘 → 标注/合成 → 训练 → 灰度。要先有权限与脱敏。

---

## 4. 评测泄漏与火车测试分离

- 按 **文档/用户/时间** 切，不要随机行切导致同文档进 train/test  
- RAG 金标问句不要写进 SFT 答案全文（模型会背答案不检索）  
- 公开 benchmark 只当参考，晋升看业务集  

---

## 5. 模型合并与汤（Merge）

不必再训，把多个权重按配方混合：

| 方法 | 一句话 |
|------|--------|
| 平均 / 加权平均 | 最朴素，任务别太冲 |
| TIES | 去符号冲突再合并 |
| DARE | 随机丢增量再缩放 |
| SLERP | 球面插值，适合两模型 |
| 任务算术 | \(W + \lambda (W_{\mathrm{task}}-W_{\mathrm{base}})\) |

用途：把「数学 LoRA」和「医疗 LoRA」拼到同一基座。风险：负迁移，必须回归评测。和「多 adapter 运行时切换」是两条路。

---

## 6. 高频问答

**Q：1 万脏数据和 1 千干净数据？**  
A：SFT 选干净。脏数据教会错误格式和幻觉自信。

**Q：如何发现污染？**  
A：看模型对「打乱选项的原题」是否仍异常准；n-gram 重叠；用更新的私有集。

**Q：合成数据能替代专家吗？**  
A：不能替代口径与安全边界。能替代部分「改写/扩多样」。

**Q：合并和 MoE 区别？**  
A：合并是一份静态权重；MoE 是运行时路由多专家。合并便宜，MoE 要专门服务化。
