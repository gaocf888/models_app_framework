## 0. 结论与已确认项

**做法**：不新造报告引擎。沿用 `/analysis-agent`：全量取数 → 质量门 → 按章合成、顺序 SSE。新增的是 **可复用板块配置** 与 **五类模版拼装**；表/图由程序渲染，LLM 只写解读。

| # | 确认项 | 落地约定 |
|---|--------|----------|
| 1 | 默认日期周期 | **上一完整周期**（见 §5.1），接口可显式覆盖起止 |
| 2 | 设备三率与告警 | 业务库暂无 → **板块占位**（待补充）；后续数据是按模版脚注现算还是已汇总，**待定**，占位结构预留两种接入 |
| 3 | 重点监测区 | 已从季报表 4-1 提炼为 `key_monitoring_areas.yaml`（§5.4） |
| 4 | 典型曲线 | 先做 **沉降极值站 + 配对水位井**；再扩 2～3 条双轴方向，**特征明显性择优**后出图 |
| 5 | 压缩层口径 | **对齐** `季度报告分层标处理.py`（层间差，不是单标 `total_settle`）；实现见 **§5.3**（查数走基座执行器 + 工程算层间差；**不把生成器当附表真源**） |
| 6 | 42 站 | **仅层位 0 代表标**；不是 `t_station` 全表；压缩层不齐的站缺层留空 |

**本期不做**：板块分槽位并行合成（取数并行已有）；地图实装（占位）；年报独立版式。

## 1. 目标与范围

把现网 `subsidence_daily/weekly/monthly/quarterly/yearly` 从 P1 占位，对齐 4 份 Word 模版的章节与图表约定，对外提供「选模版 → 出报告」。

**范围内**：模版/板块/组件配置；结构化入参；沉降与压缩层确定性计算；重点区、典型曲线；设备章占位。  
**范围外**：看图诊断；整篇一份 LLM 提示词；让 LLM 生成关键表/图数字；设备三率真实计算（无数据）。

## 2. 与现网智能体的关系

现网已具备：`report JSON`（`chapters` + `plan.items` + `tables/charts`）→ `acquire_data` 并行 → 程序表图 → 按章 `llm_section`。地降五类 JSON 目前多为骨架，季报相对完整但仍未对齐 Word。

本方案只做三处演进：

1. **板块库**：共享章节从五份 JSON 抽成可引用片段（含该板块自己的 plan 项）。  
2. **模版 = 板块引用列表** + 封面占位参数。  
3. **入参结构化**：模版类型 + 起止 + 行政区，注入 `@t_start/@t_end/area`，不再靠 `query` 猜周期。

不改主图节点顺序；合成默认串行保序。

## 3. 配置分层（组件 / 板块 / 模版）

```text
组件（渲染单元）
  narrative     LLM 文本
  table         程序 → Markdown + table_payload
  bar / line    程序 → chart_payload（双轴见 §5.5）
  map           占位
  static        封面/目录/脚注，占位符替换

板块（可复用）
  自带 plan.items + 叙述蓝图 + 可选表图
  可变体（重点区 ± 表）或循环（按行政区 / 按压缩层组）

模版
  日/周/月/季/年 = 封面 + 有序列表引用板块
```

原则：

- **不要**为每个板块写一套 Python 类；板块是配置，循环/变体用参数。  
- **不要**一份模版一份从零复制的完整数据计划；plan 按板块并集去重。  
- **不要**一份模版一篇整文 LLM 提示词；系统提示词地降共用，user prompt 按板块拼（现有 `section_prompt`）。  
- 关键数字只来自查询或确定性计算；LLM 禁止手搓宽表/关键图。

建议目录（实施时再落文件，本粗略版不拆代码）：

| 配置 | 建议位置 |
|------|----------|
| 五类报告规格（引用板块） | `configs/analysis_agent_reports/subsidence_*.json` |
| 板块库 | 同目录 `sections/` 或 JSON 内 `section_library` |
| 层位字典 | 已有 `semantic/dimensions/fcb_layer_map.yaml` |
| 重点监测区 | 已落 `semantic/dimensions/key_monitoring_areas.yaml` |

## 5. 数据与口径

### 5.1 默认上一完整周期

未传起止时按模版取 **已结束的上一自然周期**（半开区间 `[start, end)`）：

| 模版 | 默认窗 |
|------|--------|
| 日报 | 昨天 0 点 ～ 今天 0 点 |
| 周报 | 上一自然周（周一 0 点 ～ 本周一 0 点） |
| 月报 | 上一自然月 |
| 季报 | 上一自然季 |
| 年报 | 上一自然年 |

传入 `start_time`/`end_time` 则覆盖。行政区默认全市平原监测范围；传入则过滤 `t_station.area`。

### 5.2 42 站 = 层位 0 代表标

- 站点地面沉降 / 全市平原 / 分区 / 附表 1：**只取** `fcb_layer_map` 中 `monitor_layer=0` 的 `station_name`（当前 42 条）。  
- **禁止**对同 `project_name` 下全部标 AVG/SUM，**禁止**用 `t_station` 全表冒充 42 站。  
- 周期 `Δ = total_settle(窗初) − total_settle(窗末)`；**Δ>0 下沉，Δ<0 回弹**。窗内缺初或缺末的站不参与极值/排行。

### 5.3 压缩层（对齐季报脚本）

压缩层是 **固定口径的报表计算**，不是开放问句。两段拆开，避免把「不连库」和「不用 LLM 写 SQL」混为一谈：

| | 生成器（LLM 写 SQL） | 执行器（基座跑 SQL 拿行） | 工程计算 |
|--|--|--|--|
| 压缩层附表 / 分层成果 | **不作为真源**（现网仅 `compress_pairs` 注入，不足以撑附表） | **要用**：连库、`@t_start/@t_end`、权限、trace | **层间差在这里做** |
| 平原区/分区等叙述取数 | 可以用 | 用 | 一般不再做层间差 |

正确理解是：**先从业务库查到各边界标窗初/窗末（或单标 Δ），再程序算** `compress(i→i+1)`。  
不是「完全不走 NL2SQL 基座」，也不是「让生成器直接写出压缩层汇总 SQL」。查数 SQL 用**确定性模板**（或 QA 锁死的固定 SQL），走同一套执行通道；弱方案「每期让生成器现写窗初/窗末 SQL」不作为附表真源（易全标聚合、看错 `J*`/`F*` 表）。

**实现方式**：业务库只取边界标的窗初/窗末累计沉降 → 工程封装方法按脚本公式算层间差。字典用已有 `fcb_layer_map.yaml`（`semantic_layer` 已有 `layers_by_project`），**不读**原脚本的 xls/xlsx。

```text
报告时间窗 + 可选行政区
  → 读 fcb_layer_map（每站 {层位→标}，缺层无键）
  → 查数（确定性 SQL 模板 / QA 锁死 SQL，经 NL2SQL 执行器跑，禁止生成器当真源）：
       仅 monitor_layer ∈ {0,1,2,3,4} 的边界标；空层位辅助标不查
       F* → t_data_wash_fcb；J* → t_data_wash_jyb
       窗内 settle 非空的最早/最晚各一条（有效点 < 2 则跳过）
       可选 JOIN t_station 按 area 过滤
  → 工程计算（对齐 季度报告分层标处理.py 的公式，不移植 Excel 扫列/抽站点号）：
       Δ(标) = settle_start − settle_end
       仅连续对 next−curr==1：compress(i→i+1)=Δ(i)−Δ(i+1)
       缺层 / 缺初或缺末 → 该格空，不造数
  → 写入 gathered_data（与 NL2SQL 计划项同一契约）
  → 附表 2–5 程序渲染；layer_results 章 LLM 只解读
```

与季报章节对应：`0-1` 第一压缩层组，`1-2` 第二，`2-3` 第三，`3-4` 第四。

缺层（与季报脚注、字典 `note` 一致）：**F11 无第三、四；F9 / F10 无第四**。第三层组分母按有该层的站计（约 41），第四层组约 39；附表对应格留空。

接入：`acquire_data` 增加确定性计划项（如 `executor: fcb_layer_compress`），查数走基座执行器、层间差在本项内算完，与叙述用 NL2SQL 项并列；不在 `chapter_synthesize` 里再算。一次窗初/窗末拉取可同时服务 **grain B**（层位 0 → 附表 1 / 全市分区）和 **grain C**（层间对 → 附表 2–5 / 分层成果）。

产出行建议固定字段：`project_name, area, layer_from, layer_to, mark_from, mark_to, delta_from, delta_to, compress_mm`。

**不要**：对着 Excel 再跑原脚本；让生成器输出 `compress_mm` 或层间汇总 SQL 当附表真源；把全量时序灌进提示词；把 YAML 展开成长 `IN` 交给生成器碰运气。本期 **不必** 先建层位维表或报表视图（中期优化，不是算对的前提）。

### 5.5 典型曲线

程序选站、程序出双轴图，LLM 只解释。

**主路径（对齐月报图 2）**：层位 0 周期 |Δ| 最大的站 + **同 `project_name` 的水位井**（`t_data_wash_dxswj`；多井时取序列更完整者，月报例为 F21 配 D21-*）。

**再扩 2～3 条候选双轴**（同一时间窗、需双序列完整）：

1. 地面沉降（层位 0）× 地下水位（主路径）  
2. 地面沉降 × 降雨（`t_data_wash_qxz.real_time_rain`，同场地或就近）  
3. 第一压缩层组 `0-1` × 孔隙水压力（`t_data_wash_kxsylj`）  

可选第四候选：地面沉降 × GNSS 水平位移（站点能对齐时）。缺配对序列则该方向淘汰。

**择优**：对每条候选打分（辅助序列完整率、与沉降同向/反向变化幅度、|Δ| 本身），取 Top1（月报默认一张）；需要时 Top2。禁止 LLM「从六类监测里自行发现典型站」。

双轴 `chart_payload` 现网 `bar/line` 需扩展 `dual_axis`（左沉降 mm，右水位/降雨/孔压）。

### 5.6 设备三率与告警（占位）

日/周 `station_ops`、`device_alert`：**固定待补充文案 + 空表/空柱图骨架**（表头对齐模版：标编号、设备类型、位置、实时值、告警内容；柱图分设备类型）。

脚注①②③（在线率 / 完整率 / 有效率）写入 static，便于后续接数。接入时二选一（**待业务确认**）：按脚注用明细现算，或读汇总表。未确认前不写假数。

### 5.7 地图

`city_plain` 地图槽位输出占位 payload（标题 + 42 站 lon/lat 若 `t_station` 有则带上，前端可空态）。专用封装后再替换。

## 6. 生成链路（沿用主图）

```text
POST /analysis-agent/run-stream
  结构化 options → 默认上一完整周期 / 区划
  → 模版展开板块（循环展开为多章）
  → plan 并集去重
  → intent_rag（口径知识，不算数）
  → acquire_data（叙述用 NL2SQL 生成+执行 ∥ 压缩层：执行器查初末 + 工程层间差，见 §5.3）
  → data_quality（mandatory 空则待补充；设备占位不阻断）
  → 程序渲染表/图
  → 按板块 LLM 叙述（串行 emit）
  → finalize
```

压缩层与附表 2–5：查数走 NL2SQL **执行器**（确定性 SQL），层间差工程计算（§5.3）；**生成器不当附表真源**。层位 0 全市/分区/重点区叙述仍可用生成器，问句必须钉死层位 0 清单；若已走同一次窗初/窗末拉取，附表 1 可直接复用 grain B。典型曲线时序建议专用查询或确定性拉序列，避免宽表进 LLM。

## 7. 对外接口

仍用 `POST /analysis-agent/run-stream`。`analysis_type` 即模版。建议 `options` 增加：

| 字段 | 说明 |
|------|------|
| `start_time` / `end_time` | 可选；缺省 = 上一完整周期 |
| `area` | 可选；缺省全市（有监测站的平原区，不是北京 16 区全切） |
| `issue_no` | 可选；封面「第 XX 期」，无则占位 |

`query` 可留补充说明，**不是**时间范围真源。前端「自动报告」只传类型 + 可选日期/区划即可。

## 9. 明确不做（本粗略版）

- 板块合成并行（取数并行保持）  
- 一篇提示词生成整份报告  
- LLM 输出关键表/图源码当数字真源  
- 用 `t_station` 全表或全标聚合冒充 42 站 / 压缩层  
- 用 NL2SQL **生成器**临场写层间/压缩层汇总 SQL 当附表真源，或把原 Excel 脚本当运行时入口（查数仍走基座执行器，见 §5.3）  
- 设备三率在无数据时用「有数天数」等近似冒充①②③  
- 年报单独版式、地图实装、看图诊断接入
